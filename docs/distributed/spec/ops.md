# OPS requirements

Requirement text is taken from SPEC.md.

- OPS-001: Provide reproducible DietPi ARM64 installation, service, administrator, TLS and LAN setup.
- OPS-002: Present the final HTTPS URL and browser trust instructions.
- OPS-003: Normal setup MUST NOT require source edits or manual cryptographic material generation.
- OPS-004: Provide local-administrator-controlled password reset, certificate replacement and recovery.
- OPS-005: Document upgrades, mixed-version compatibility and rollback constraints.
