# REPO requirements

Requirement text is taken from SPEC.md.

- REPO-001: Inspect the current repository and identify existing CLI entry points, domain operations, state machines, SQLite schemas, provider orchestration, terminal integration, tests and CI.
- REPO-002: Identify and preserve authoritative implementations of provider selection, rotation, retries, capacity, mission lifecycle, task verification, process ownership and recovery.
- REPO-003: Run existing relevant tests and record baseline failures, CLI behaviour, database versions and platform constraints.
- REPO-004: Preserve existing repository conventions. Avoid unrelated refactoring.
- REPO-005: Perform reconnaissance once. Revisit only specific files or decisions when implementation evidence requires it.
