# WEB requirements

Requirement text is taken from SPEC.md.

- WEB-001: Support current Chrome and Firefox on desktop and Android with a responsive TypeScript frontend.
- WEB-002: Require no extensions, installed client or runtime Node.js server.
- WEB-003: Deliver professional, accessible, modern UX with coherent light/dark themes.
- WEB-004: Provide overview, workers, missions, tasks, sessions, activity, provider usage and health/diagnostics.
- WEB-005: Support mission inspection, approvals/rejections, lifecycle controls and live monitoring.
- WEB-006: Clearly distinguish live, reconnecting, offline and stale states.
- WEB-007: Use xterm.js or equivalent mature terminal rendering.
- WEB-008: Preserve terminal resizing, keyboard input, copy/paste, reconnection and single-writer ownership.
- WEB-009: Target WCAG 2.2 AA.
- WEB-010: Keep loading and memory consumption low; paginate or virtualise large histories.
- WEB-011: Confirm destructive actions and validate server-side.
- WEB-012: Operate without internet connectivity after installation.
